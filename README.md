## 🛠️ Building the CV

To generate the PDF version of the CV from LaTeX sources, run the following command from the root of the repository:
```bash
./build
```

This script uses `pdflatex` internally to compile the `mateuszstompor.tex` file.  
Ensure you have a LaTeX distribution installed (e.g., TeX Live or MiKTeX) and that `pdflatex` is available in your system’s PATH.

The output will be located in `distribution` and named `Mateusz Stompór - CV - {BUILD_DATE}.pdf`.
